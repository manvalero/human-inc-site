Wikipedia

In 2011, Wikimedia began developing VisualEditor to edit Wikipedia without working directly in wikitext. In 2012, much of its early implementation was rebuilt, while Parsoid connected the visual editing surface to Wikipedia’s existing wikitext. During testing, VisualEditor was made increasingly modular and extensible. Over time, it developed from an editing interface into a platform powering Content Translation, DiscussionTools, Structured Tasks and Edit Check. Edit Check became a framework for Reference Check, Tone Check and Link Check. Generation as an open sequence.
